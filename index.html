LPG/CNG ECU Diagnostics

Flutter · Dart · Bluetooth & USB OTG · fl_chart

An Android app that reads telemetry from a gas ECU over Bluetooth or USB OTG and finds the likely fault with a rule-based engine. It compares gas rail overpressure with injector duty, and each injector with the per-sample median, to tell a clogged filter, an unstable or mis-set reducer, a restricted or open injector and a faulty sensor apart. The dashboard has live gauges, charts and a diagnosis tab. A built-in ECU simulator and unit tests cover the fault scenarios, and the wire protocol is a placeholder to adapt to a real ECU.

Network Diagnostics Engine

Python · Scapy · Rich

A command-line toolkit that finds path problems, latency bottlenecks and PMTUD blackholes. It sends DF-bit ICMP probes and binary-searches the largest working MTU, then runs a TTL sweep to find the link that silently drops large packets. It reports per-hop loss, RTT and jitter and separates real bottlenecks from ICMP rate limiting. Results appear in a Rich terminal UI and as JSON, text or HTML reports, with exit codes for scripts and CI.
